## Что делаем (только фронтенд, без бизнес-логики)

### 1. Семантический HTML — `src/pages/Index.tsx`
Обернуть весь контент после `<Header>` в `<main id="main-content">`. Footer оставить вне `<main>`. Это даёт +7 баллов в GEO без риска: компоненты внутри уже используют `<section>`.

### 2. Видимая контактная форма — `src/pages/Index.tsx` + использовать существующий `HeroCallbackForm`
Добавить компактный блок-форму обратного звонка сразу после `<Hero>` (перед `<MiniPricing>`), обёрнутый в `<section aria-label="Заказать обратный звонок">`. Компонент `HeroCallbackForm` уже существует, имеет 2 поля (имя + телефон) — вписывается в требование ≤5 полей. SSR-безопасен (уже используется в проекте).

### 3. Каналы связи в статическом HTML — обновить `src/components/Footer.tsx`
Добавить в футер видимый блок ссылок-мессенджеров (`<a href="https://t.me/one_help">Telegram</a>`, `<a href="https://max.ru/...">MAX</a>`, `<a href="tel:...">Звонок</a>`) с иконками. Сейчас они только в `FloatingButtons` (рендерятся через JS). Это даёт +6 баллов CRO. WhatsApp не добавляем (запрещено memory).

### 4. Мультимодальность — `src/components/WorkGallery.tsx`
Заменить `<div>` обёртки изображений на `<figure>` + `<figcaption>` с подписью (текущий `item.title` + `item.desc`). Подпись стилизуется как уже отображаемый текст под фото — визуально не меняется, но семантически корректно. +5 баллов AI.

### 5. Дополнительный CTA выше первого экрана — `src/components/Hero.tsx`
Рядом с существующей кнопкой «Рассчитать стоимость» добавить вторичную кнопку «Позвонить» (`tel:84950181817`). Это даёт второй CTA выше fold → +3-5 баллов CRO. Кнопка `variant="outline"`, стилизована под Hero.

### 6. Короткий цитируемый блок — `src/pages/Index.tsx`
После Hero (внутри новой `<section>`) добавить лаконичный блок-«ответ»: 2-3 коротких предложения «Что мы делаем / Сколько стоит / Гарантия» в виде `<p>` с `aria-label="Краткая информация"`. Это и для GEO «прямые ответы», и для CRO визуально полезно.

- Бизнес-логику, маршруты, SEO-схемы, генератор метаданных

- Floating buttons (оставляем как есть — дублируют, но не мешают)
- Никаких бэкенд-изменений, миграций, edge-функций
- `seoRoutes.ts`, SSG-пайплайн, `index.html`
