

# Редизайн FloatingButtons — одна кнопка с раскрывающимся меню

## Что сейчас
Две отдельные кнопки (телефон + MAX) висят в правом нижнем углу. Нет Telegram. Иконки — generic lucide.

## Что будет
Одна главная кнопка (плюс/крестик). При нажатии раскрывается "ёлочка" снизу вверх с тремя опциями:
1. **Телефон** — звонок (зелёная кнопка, lucide `Phone`)
2. **MAX** — мессенджер (синяя #168DE2, SVG-иконка MAX)
3. **Telegram** — @one_help (голубая #26A5E4, SVG-иконка Telegram)

Каждая кнопка с тултипом-лейблом слева. Анимация — staggered fade+slide снизу вверх.

## Технические детали

### Файл: `src/components/FloatingButtons.tsx` — полная перезапись

- **Состояние**: `isOpen` (boolean) вместо двух тултипов
- **Главная кнопка**: иконка `X` когда открыто, `MessageCircle` когда закрыто. Цвет primary.
- **SVG-иконки**: inline SVG для Telegram (официальный самолётик) и MAX (стилизованная "M" или bubble). Не lucide — реальные бренд-иконки.
- **Анимация**: CSS transitions с `delay` для каждой кнопки (0ms, 75ms, 150ms) — эффект ёлочки.
- **Клик вне**: закрытие меню при клике за пределами компонента.
- **Ссылки**:
  - Телефон: `tel:84950181817`
  - MAX: текущий URL max.ru
  - Telegram: `https://t.me/one_help`

### Анимация раскрытия
```text
[закрыто]     [открыто]
              ✈ Telegram    ← появляется 3-й (delay 150ms)
              M MAX         ← появляется 2-й (delay 75ms)  
              📞 Позвонить  ← появляется 1-й (delay 0ms)
   💬            ✕          ← главная кнопка (toggle)
```

### Что НЕ меняется
- Index.tsx — импорт остаётся тот же
- Аналитика `trackGoal` — сохраняется для phone_click
- Позиция: `fixed bottom-6 right-6 z-50`
